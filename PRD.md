# PRD: AI Executive Assistant — «Вторая голова»

**Версия:** 1.0  
**Дата:** 31 мая 2026  
**Владелец продукта:** Личный ассистент члена правления и ГД АО «Казахтелеком»  
**Статус:** Draft → Review

---

## 1. Обзор продукта

### 1.1 Цель

Создать персонального AI Executive Assistant (далее — EA), который работает как операционный центр управления для личного ассистента члена правления и Генерального директора АО «Казахтелеком». EA берёт на себя рутину, хранит контекст всех задач и направлений, контролирует сроки и освобождает когнитивную нагрузку пользователя.

### 1.2 Ценностное предложение

| Боль | Решение EA |
|---|---|
| Задачи теряются в потоке | Единая база всех поручений с дедлайнами и статусами |
| Приходится держать всё в голове | EA помнит контекст и напоминает сам |
| Много направлений одновременно | Структурированные модули по каждому направлению |
| Подготовка документов отнимает время | Шаблоны и генерация текстов по запросу |
| Нет единой картины дня/недели | Сводный дашборд и ежедневный бриф |

### 1.3 Пользователь

**Один первичный пользователь** — личный ассистент члена правления и ГД «Казахтелеком».

Профиль: высокая нагрузка, множество параллельных направлений, работа в зоне высокой ответственности, критична безошибочность и конфиденциальность.

---

## 2. Контекст и ограничения

- Все данные конфиденциальны; хранение — только на устройствах пользователя или в одобренных корпоративных системах.
- Интерфейс взаимодействия — чат (текст + структурированные команды).
- MVP реализуется как набор модулей в едином рабочем пространстве (Markdown-файлы + Claude Code как AI-движок).
- Язык интерфейса и коммуникации — русский.
- Часовой пояс — Алматы (UTC+5).

## 3. Модули системы

### Модуль 1. Календарь и расписание руководителя

**Цель:** ни одна встреча не потеряна, нет пересечений, руководитель всегда подготовлен.

**Функции:**
- Создание и хранение записей о встречах (дата, время, участники, тема, локация/формат)
- Автоматическое выявление конфликтов в расписании
- Генерация ежедневного и еженедельного дайджеста расписания
- Напоминания за 24 ч / 1 ч до события
- Фиксация переносов с историей изменений
- Подготовка брифа к встрече по запросу

**Хранилище:** `calendar/events.md`, `calendar/weekly.md`

**Команды пользователя:**
```
/встреча [дата] [время] [тема] [участники]
/расписание сегодня
/расписание неделя
/перенести [ID встречи] на [новая дата/время]
/бриф к встрече [ID]
```

---

### Модуль 2. Совещания и поручения

**Цель:** каждое поручение зафиксировано, каждый дедлайн под контролем.

**Функции:**
- Подготовка шаблона agenda по запросу
- Ведение протокола совещания (диктовка → структурированный документ)
- Автоматическое извлечение поручений из протокола
- Присвоение ответственного, дедлайна и статуса каждому поручению
- Еженедельный отчёт по открытым поручениям
- Генерация follow-up письма / сообщения по итогам встречи

**Статусы поручений:** `Новое` → `В работе` → `На проверке` → `Выполнено` / `Просрочено`

**Хранилище:** `meetings/[YYYY-MM-DD]-[тема].md`, `tasks/assignments.md`

**Команды:**
```
/совещание новое [тема] [дата]
/протокол [совещание ID]
/поручение добавить [текст] [ответственный] [дедлайн]
/поручения открытые
/followup [совещание ID]
```

---

### Модуль 3. Обучение вайбкодингу — база учеников

**Цель:** ни один ученик не потерян, оплаты под контролем, группы управляемы.

**Функции:**
- Карточка ученика: ФИО, контакт, группа, дата старта, тариф, статус оплаты
- Регистрация нового участника
- Статус оплаты: `Ожидает` / `Оплачено` / `Просрочено` / `Рассрочка`
- Напоминания об оплате (за 3 дня, в день, +3 дня просрочки)
- Чек-лист прохождения программы по ученику
- Сводный отчёт по группе: прогресс, оплаты, активность
- Список участников для экспорта

**Хранилище:** `vibecoding/students.md`, `vibecoding/groups/[group-name].md`

**Команды:**
```
/ученик добавить [ФИО] [телефон] [группа] [тариф]
/ученик [ФИО] статус
/оплата [ФИО] [сумма] [дата]
/группа [название] отчёт
/должники список
```

---

### Модуль 4. Instagram-бизнес — вайбкодинг

**Цель:** стабильный поток контента и заявок без прокрастинации на «что писать».

**Функции:**
- Контент-план на неделю / месяц (тема, формат, дата публикации, статус)
- Генерация идей для Reels (хук + сценарий + CTA)
- Написание текста поста (продающий / обучающий / прогревочный / вовлекающий)
- Подготовка описания к публикации с хэштегами
- Воронка заявок: `Лид` → `Консультация` → `Оплата` → `Обучение` / `Отказ`
- Учёт потенциальных клиентов с историей касаний

**Хранилище:** `instagram/content-plan.md`, `instagram/leads.md`

**Команды:**
```
/контент план неделя
/reels идея [тема]
/пост [тип] [тема]
/лид добавить [ФИО] [контакт] [источник]
/воронка статус
```

---

### Модуль 5. Digital Office — HR и табель

**Цель:** прозрачный учёт рабочего времени и движения сотрудников.

**Функции:**
- Табель учёта рабочего времени (сотрудник, даты, явки/отсутствия)
- Учёт отсутствий: больничный, отпуск, отгул, командировка
- График отпусков на год
- Контроль командировок сотрудников (заявка → приказ → авансовый отчёт)
- Ежемесячный сводный отчёт по подразделению

**Хранилище:** `digital-office/timesheet-[YYYY-MM].md`, `digital-office/vacations.md`, `digital-office/trips.md`

**Команды:**
```
/табель [месяц]
/отсутствие [сотрудник] [тип] [даты]
/отпуск [сотрудник] [даты]
/командировка сотрудник [ФИО] [цель] [даты]
/отчёт DO [месяц]
```

---

### Модуль 6. Командировки

**Цель:** ни одна командировка не закрыта с опозданием, все документы собраны.

**Направления учёта:**
- Мои командировки
- Командировки Генерального директора Digital Office
- Командировки сотрудников
- Командировки Татьяны Юрьевны

**Жизненный цикл командировки:**
```
Заявка → Согласование → Приказ → Командировка → Авансовый отчёт → Закрытие
```

**Функции:**
- Карточка командировки: кто, куда, цель, даты, бюджет, статус
- Чек-лист документов по каждой командировке
- Контроль срока сдачи авансового отчёта (стандарт: 3 рабочих дня после возвращения)
- Уведомления о просроченных авансовых отчётах
- Сводный реестр командировок за период

**Хранилище:** `trips/registry.md`, `trips/[person]/[YYYY-MM]-[destination].md`

**Команды:**
```
/командировка новая [кто] [куда] [даты] [цель]
/авансовый отчёт [ID] получен
/командировки открытые
/командировки просроченные
```

---

### Модуль 7. Финансы

**Цель:** полная прозрачность расходов, нулевые сюрпризы при сверке.

**Функции:**
- Журнал расходов руководителя с категориями
- Отдельный учёт расходов по корпоративной карте
- Список чеков к сдаче с отметками о получении
- Контроль авансовых отчётов по расходам
- Ежемесячная сводка: план vs факт по категориям
- Напоминание о закрытии авансовых отчётов

**Категории расходов:** Представительские / Транспорт / Размещение / Питание / Канцелярия / Прочее

**Хранилище:** `finance/expenses-[YYYY-MM].md`, `finance/corp-card.md`

**Команды:**
```
/расход [сумма] [категория] [описание] [дата]
/карта [сумма] [категория] [описание] [дата]
/чек добавить [описание] [сумма] [статус]
/финансы сводка [месяц]
/авансовый закрыть [ID]
```

### Модуль 8. Личные поручения руководителя

**Цель:** ни одно поручение не потеряно и не просрочено.

**Функции:**
- Реестр поручений с приоритетом (Срочно/Важно/Обычно), дедлайном и статусом
- Напоминания за 2 дня и в день дедлайна
- Еженедельный отчёт: выполнено / в работе / просрочено
- История выполненных поручений с датой закрытия

**Матрица приоритетов (Эйзенхауэр):**

| | Срочно | Не срочно |
|---|---|---|
| **Важно** | Сделать сейчас | Запланировать |
| **Не важно** | Делегировать | Удалить |

**Хранилище:** `assignments/active.md`, `assignments/archive.md`

**Команды:**
```
/поручение [текст] [дедлайн] [приоритет]
/поручения список
/поручение закрыть [ID]
/поручения отчёт неделя
```

---

### Модуль 9. Личная эффективность

**Цель:** структурированный день, выполнение важного, а не только срочного.

**Функции:**
- Ежедневный чек-лист (генерируется утром на основе задач и встреч дня)
- Еженедельное планирование (в пятницу вечером / понедельник утром)
- Список целей: квартальные → недельные → ежедневные
- Вечерний итог дня: что сделано, что перенесено, блокеры
- Трекер энергии и фокуса (опционально)

**Ритм работы с EA:**

| Время | Действие |
|---|---|
| 08:00 | Утренний бриф: встречи дня + топ-3 задачи + просроченные |
| 18:00 | Вечерний итог: закрытые задачи + незакрытые + план на завтра |
| Пятница 17:00 | Недельный итог + план следующей недели |

**Хранилище:** `personal/daily-[YYYY-MM-DD].md`, `personal/goals.md`, `personal/weekly.md`

**Команды:**
```
/утро
/вечер
/цель добавить [текст] [срок]
/неделя план
/неделя итог
```

## 4. Сквозные функции

### 4.1 Единый дашборд (команда `/дашборд`)

Выводит сводку по всем модулям:
- Встречи сегодня и завтра
- Просроченные поручения (любые)
- Должники по обучению
- Открытые командировки без авансового отчёта
- Топ-3 личных задачи на день
- Незакрытые авансовые отчёты

### 4.2 Умные напоминания

EA сам инициирует напоминания при каждом обращении пользователя, если обнаружены:
- Просроченные дедлайны
- Встречи в течение 2 часов
- Командировки без закрытых документов
- Задолженности по оплате обучения

### 4.3 Генерация документов

По запросу EA готовит:
- Письма и уведомления
- Протоколы совещаний
- Отчёты по любому модулю
- Agenda встречи
- Follow-up сообщения
- Посты и тексты для Instagram

### 4.4 Контекстная память

EA хранит и использует:
- Историю всех задач и статусов
- Профили ключевых контактов (ГД, Татьяна Юрьевна, сотрудники, ученики)
- Паттерны предпочтений пользователя
- Незакрытые вопросы из прошлых сессий

## 9. Принципы работы EA

1. **Структура важнее объёма** — короткий структурированный ответ лучше длинного текста
2. **Всегда предлагай следующий шаг** — каждый ответ заканчивается действием
3. **Не жди — напоминай** — при каждом обращении проверяй просроченное
4. **Контекст хранится** — не нужно объяснять каждый раз с нуля
5. **Конфиденциальность** — данные о руководителе не упоминаются в небезопасном контексте
6. **Один источник правды** — все данные в файлах, не в памяти разговора
