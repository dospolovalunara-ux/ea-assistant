# Интеграции

Каждая внешняя система подключается через свой адаптер в этой папке, чтобы провайдера можно было заменить.

Пока ни одна интеграция не подключена. Интерфейс честно показывает «Не подключено» / «В разработке».

План (см. `docs/PRD.md`):
- `google-calendar/` — OAuth + PKCE, scope `calendar.events`, refresh-token шифруется AES-256-GCM (Sprint 2b);
- `ai/` — AI-адаптер, пишет только в `ai_extractions` (Sprint 3b, после согласования провайдера);
- `ocr/`, `stt/`, `export/` — Sprint 4–5.
